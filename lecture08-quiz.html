Ae-Stat

Q2SSDSE（教育用標準データセット）の説明として正しいのは？
A教育用に作られた架空（フェイク）のデータ
B政府統計を教育用に整備した版で、中身は本物の政府統計

Q3本科目で使う SSDSE のファイルはどれ？（サイトにはA〜Eの5種類が並ぶ）
ASSDSE-A（市区町村のデータ）

C基本素材（SSDSE-E）の SSDSE-E-2026.csv
Dどれでも結果は同じ
正解: C
5種類（A〜E）のうち「基本素材（SSDSE-E）」の SSDSE-E-2026.csv を選びます。ファイル名で確認しましょう。
Q4統計ダッシュボード（dashboard.e-stat.go.jp）の特徴は？
A自分のCSVをアップロードして保存する場所
BExcelマクロを書いて集計する場所

Dできあがったグラフを眺めるだけで全体像がつかめる

Q1SSDSE を pd.read_csv("SSDSE-E-2026.csv") で読むと UnicodeDecodeError が出た。原因は？
Aファイルが壊れている
B文字コードの違い（cp932 と UTF-8 の食い違い）
Cインターネットに接続していない
D列が多すぎて読めない
正解: B
政府統計のCSVはcp932が多い。pandasは既定でUTF-8と思って読むのでエラーになります。
Q2SSDSE 読み込みの「完成形」コードはどれ？
Apd.read_csv("SSDSE-E-2026.csv", encoding="cp932", skiprows=[0, 1])
Bpd.read_csv("SSDSE-E-2026.csv")
Cpd.read_csv("SSDSE-E-2026.csv", sep="cp932")
Dpd.read_excel("SSDSE-E-2026.csv")
正解: A
encoding="cp932" で文字コードを、skiprows=[0, 1] で先頭2行を飛ばすのが完成形です。
Q3skiprows=[0, 1] は何をする指定？
A先頭の1行だけ飛ばす
B2行目と3行目を飛ばす（1行目は残す）
C先頭の2行（0番目と1番目）を飛ばす
D最後の2行を飛ばす
正解: C
SSDSEは3段ヘッダー。0番目(列コード)と1番目(年度)を飛ばし、3行目の日本語列名を使います。
Q4読み込み後 df.shape が (48, 95) になった。47都道府県のはずが1行多い理由は？
A空っぽの行が混ざっているから
Bヘッダー行が残っているから
C同じ県が重複しているから
D1行目に「全国」の合計行が入っているから
正解: D
先頭の「全国」行を df[df["都道府県"] != "全国"] で除外すると (47, 95) に整います。
Q5総人口の多い順に上位10県を表示するコードは？
Adf.sort_values("総人口", ascending=True).head(10)
Bdf.sort_values("総人口", ascending=False).head(10)
Cdf.head(10)
Ddf.sort_values("総人口")
正解: B
sort_valuesで並べ替え、ascending=Falseで降順（多い順）、.head(10)で上位10件です。

Q147行から「北海道」の行だけを抜き出すコードは？
Adf[df["都道府県"] == "北海道"]
Bdf["北海道"]
Cdf == "北海道"
Ddf.北海道
正解: A
内側の条件 df["都道府県"] == "北海道" を角括弧に入れると、その行だけが残ります。
Q2df["都道府県"] == "北海道" が返すものは？
A「北海道」という文字列そのもの
B北海道の行数（数字）
C各行が北海道かどうかの True / False が並んだ列
Dエラー
正解: C
== は各行に「北海道か？」と聞き、True/Falseの列を作ります。これを角括弧に入れるとTrueの行だけ残ります。
Q3出身県を抜き出したら 0 行（空）になった。最も疑うべきは？
Aファイルが壊れている
B出身県の表記ミス（「東京」だけ書いた等）
Cencodingの指定が違う
Dskiprowsが足りない
正解: B
SSDSEの表記は「東京都」「大阪府」「京都府」「北海道」、それ以外は末尾まで「○○県」。1字でも違うと0行になります。
Q4全国平均を mean() で出すとき、なぜ先に数値の列だけに絞る？
Amean()は1列しか扱えないから
B計算を速くするため
C列が多すぎるとmeanが使えないから
D「都道府県」のような文字の列が混ざると平均が計算できずエラーになるから
正解: D
「北海道＋青森」は足せません。先に数値の5列だけに絞ってから .mean() を呼びます。
Q5出身県の特徴は、どう読み取ると考察が書きやすい？
A総人口が1位かどうかだけ見る
Bすべての指標が平均を上回っているか確認する
C全国平均を上回る指標と下回る指標の「混ざり方」に注目する
D数字は見ずに印象で書く
正解: C
上回る指標と下回る指標が混ざるところに「なぜ」が生まれ、それが考察の素になります。
