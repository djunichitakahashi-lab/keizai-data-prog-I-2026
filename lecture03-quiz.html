Q1import pandas as pd の as pd の意味は？
Apandas に pd というあだ名（別名）をつける
Bpd というファイルを読み込む
Cpandas のバージョンを pd として指定する
Dpd を新しい変数として定義する
正解: A
as pd は「pandas を pd という短い名前で呼べるようにする」という意味の別名（エイリアス）構文です。世界共通の慣習として pd が使われます。
Q2pandas の主な役割として正しいのは？
Aグラフ（散布図など）を描くこと
B動画ファイルを再生すること
Cファイルを Colab にアップロードすること
DCSV やExcelのような表データを扱うこと
正解: D
pandas は 表（行・列）形式のデータを扱うライブラリです。CSV を読む、列を取り出す、統計量を見るなどに使います。
Q3import pandas as pd を書かずに pd.read_csv(...) を実行するとどうなる？
A自動で pandas が読み込まれて動く
BCSV は読めるが DataFrame にはならない
CNameError が出て使えない
D警告は出るが普通に動く
正解: C
import 文を書かないと pd という名前が存在しないため NameError: name 'pd' is not defined が出ます。pandas を使う前に必ず import pandas as pd を書きます。
Q4pandas のあだ名として pd を使う理由として最も正しいのは？
APython 公式が pd という名前を強制している
B世界共通の慣習で、コードを読みやすくするため
Cpandas 側のソースコードに pd がハードコードされているから
D短い名前ならどんな名前でも自由に決めて良いから
正解: B
pd は世界中の pandas ユーザーが使う慣習です。pd.read_csv や pd.DataFrame という形でコードを読めば誰でも理解できる、という共通言語になっています。

Q2CSV は何の略？
AComputer Standard Value
BCode Style Vector
CCommon Source Variable

DURL を表す文字列（"https://..."）

Q5URL方式（pd.read_csv(url)）の利点として最も正しいのは？

BAI が CSV の中身を勝手に書き換えてくれる
CCSV ファイルが軽量化される
D文字化けが絶対に起きない

URL 方式の利点は、ネット上に公開されている CSV を、ダウンロード不要で直接読み込めることです。1行で完結するので、教材や公開データに最適。手元のCSVを読むときはアップロード方式（トピック4）を使います。

Q1files.upload() を実行すると何が起きる？
ACSV が自動でダウンロードされる
Bグラフが描画される
CColab に「ファイルを選択」ボタンが表示され、自分のPCのCSVを選んでアップロードできる
DURL から CSV が読み込まれる
正解: C
files.upload() は Colab に「ファイルを選択」ボタンを表示します。クリックすると自分のPCからCSVを選んでアップロードできます。最初に from google.colab import files が必要です。
Q2アップロード後に pd.read_csv("Davis.csv") で読み込めない、最も多い原因は？
Aファイル名のスペル違い（大文字小文字・拡張子の違いを含む）
BDavis データだけは特別な関数が必要
Cpandas のバージョンが古い
DCSV のサイズが大きすぎる
正解: A
つまずきの第1位はファイル名の不一致です。Colab は大文字小文字を区別するため、Davis.csv と davis.csv は別ファイル扱いです。Colab 左のファイルパネルで実際の名前を確認してコピペするのが確実です。
Q3日本語の CSV を読んだら文字化けした。対処法は？
Aファイル名を英語に書き換える
Bpd.read_csv("...", encoding="shift_jis") のように encoding を指定する
CExcel で開き直して保存する
Dデータを半角英数字に書き換える
正解: B
日本語 CSV が文字化けする場合は encoding="shift_jis" を引数に追加します。e-Stat や SSDSE のような日本のデータでよく使う指定です。
Q4Colabのランタイムが切れた後、アップロード済みの CSV を読もうとするとどうなる？
Aそのまま読める
Bキャッシュから自動で復元される
CFileNotFoundError が出るので、再アップロードが必要
D自動で再アップロードされる
正解: C
Colab のランタイムが切れる（しばらく操作しない、ブラウザを閉じる、など）と、アップロードしたファイルも消えます。FileNotFoundError が出たら、左のファイルパネルで実物を確認し、無ければ再アップロードします。
Q5URL方式とアップロード方式の使い分けとして正しいのは？
AURL方式は手元のCSVに、アップロード方式は公開データに使う
BURL方式は文字化けを防げ、アップロード方式は文字化けする
Cどちらも全く同じで、好みで選ぶ
DURL方式は公開データに、アップロード方式は手元のCSVに使う
正解: D
URL方式は ネット上に公開された CSV（教材データ、政府統計など）に使い、アップロード方式は 自分の PC にあるCSV（課題で配られたファイル、自分でダウンロードしたデータ）に使います。両方使い分けられると、現実のあらゆるデータに対応できます。

Q1import matplotlib.pyplot as plt の plt は何？
Amatplotlib.pyplot のあだ名（エイリアス）
Bmatplotlib のプラグイン名
Cプロットされたグラフのファイル
Dmatplotlib のバージョン番号
正解: A
plt は matplotlib.pyplot の世界共通のあだ名です。pandas の pd と同じく、as plt で別名を付けることでコードを短く書けます。
Q2plt.scatter(df["height"], df["weight"]) の引数の順番は？
A1つ目=縦軸、2つ目=横軸
Bアルファベット順で先のものが横軸
Cどちらでも自動で良い方に並べてくれる
D1つ目=横軸、2つ目=縦軸
正解: D
plt.scatter(x, y) は 1つ目が x（横軸）、2つ目が y（縦軸）です。例: plt.scatter(df["height"], df["weight"]) なら、横軸が身長、縦軸が体重になります。
Q3matplotlib でグラフを明示的に表示する命令はどれ？
Aplt.scatter(x, y)
Bplt.show()
Cplt.title("グラフ")
Dplt.xlabel("X軸")
正解: B
matplotlib の本来の流れは 準備（scatter / title / xlabel）→ 表示（show）。Colab/Jupyter は親切に plt.show() を省略しても自動表示しますが、素の Python スクリプトでは plt.show() を書かないと画面に出ません。
Q4グラフの横軸ラベルに「Height (cm)」を表示したい。正しい命令は？
Aplt.label("Height (cm)")
Bplt.xlabel("Height (cm)")
Cplt.xtitle("Height (cm)")
Dplt.x("Height (cm)")
正解: B
横軸ラベルは plt.xlabel("...")、縦軸ラベルは plt.ylabel("...")、タイトルは plt.title("...") です。日本語はColabのデフォルトでは文字化けするので、英語で書きます。
Q5Davisデータの散布図（横軸=身長、縦軸=体重）を描くと、点がどんな並び方をする？
A右上がり（身長が高い人ほど体重も重い傾向）
B点がランダムに散らばり、傾向が見えない
C水平に並ぶ（身長と体重に関係がない）
D右下がり（身長が高い人ほど体重が軽い）
正解: A
Davis データでは「身長が高い人ほど体重も重い」という正の相関があり、散布図は右上がりの分布になります。これは第2回でAIが描いた図と同じ特徴です。
